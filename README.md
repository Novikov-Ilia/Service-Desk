# Service-Desk

Backend-сервис для обработки пользовательских заявок.

Проект представляет собой Service Desk / mini-CRM систему, в которой клиенты могут создавать обращения, сотрудники поддержки — брать заявки в работу и отвечать на них, менеджеры — контролировать процесс обработки, а администраторы — управлять пользователями и справочниками.

## Статус проекта

Проект находится в разработке.

## Технологии

- Django 6.0.6
