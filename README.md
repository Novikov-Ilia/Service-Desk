# Service-Desk

Backend-сервис для обработки пользовательских заявок.

Проект представляет собой Service Desk / mini-CRM систему, в которой клиенты могут создавать обращения, сотрудники поддержки — брать заявки в работу и отвечать на них, менеджеры — контролировать процесс обработки, а администраторы — управлять пользователями и справочниками.

## Статус проекта

Проект находится в разработке.

## Технологии

- Django 6.0.6

## Структура приложений

### `tickets`

Приложение отвечает за работу с заявками пользователей.

Основные модели:

- `Ticket` — заявка пользователя.
- `Comment` — комментарий к заявке.
- `Category` — категория заявки.
- `StatusHistory` — История изменении заявки.
- `CustomUser` — Кастомный пользователь, поддерживающий роли.

## Django Admin

Для проекта настроена админ-панель Django, которая используется как внутренний инструмент для ручной проверки и управления данными.

В админке зарегистрированы основные модели:

- `Ticket` — заявки пользователей;
- `Category` — категории заявок;
- `Comment` — комментарии к заявкам;
- `StatusHistory` — история изменения статусов.

Для моделей настроены:

- отображение важных полей в списках через `list_display`;
- фильтрация по статусам, категориям, пользователям и датам;
- поиск по ключевым полям;
- кликабельные ссылки на связанные объекты;
- оптимизация отображения связанных данных через `list_select_related`.

Админка позволяет быстро проверять связи между пользователями, заявками, комментариями и историей статусов во время разработки.

## База данных

Проект использует PostgreSQL.
